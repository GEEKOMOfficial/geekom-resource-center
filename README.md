# GEEKOM Resource Center

Official technical resources, setup guides, tested configurations,
and practical use cases for GEEKOM Mini PCs.

This repository is currently under development. New guides and
validated use cases will be added progressively.

## About This Repository

This repository serves as an index of technical guides and practical
use cases tested on GEEKOM hardware.

Each published guide will identify its tested device, hardware
configuration, software environment, test method, and known limitations.

## Current Project

| Category | Guide | Status |
| --- | --- | --- |
| Local AI | Run a Local AI Assistant on a GEEKOM Mini PC | Testing |

The first project is evaluating a browser-based local text assistant
using Ollama and Open WebUI on selected GEEKOM Mini PCs.

Detailed hardware configurations, model versions, test results, and
known limitations will be published after technical validation.

Status definitions:

- **Testing** — Currently being tested on GEEKOM hardware
- **Drafting** — Documentation is being prepared
- **Technical Review** — Content is being checked for technical accuracy
- **Published** — Guide is publicly available

## About the Guides

Published technical guides and test results will specify:

- Tested GEEKOM model
- Hardware configuration
- Operating system and software versions
- Test method
- Known limitations

Technical instructions, commands, scripts, and test results will be
reviewed before publication.

Results may vary depending on the hardware configuration, software
version, system settings, and operating environment.
